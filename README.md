# 消消乐 Rogue

一个用 Godot 4.6 制作的单屏泡泡肉鸽。彩色怪物挂在天花板上，慢慢往下压。你站在底部瞄准，武器会按时间自己往上发射。

## 如何打开

1. 安装 [Godot 4.6](https://godotengine.org/download) 标准版（不需要 .NET）。
2. 打开 Godot，选择「导入」，选中本目录的 `project.godot`。
3. 导入后按 F5，或点编辑器右上角的运行按钮。

主场景是 `scenes/main.tscn`。画面用 ColorRect、Polygon2D 和引擎自带控件，没有外部素材包。中文会用系统里已有的字体（微软雅黑、苹方、Noto Sans CJK、文泉驿微米黑等）。

## 操作

- **瞄准**：移动鼠标，或按左右方向键、`A` / `D`。子弹笔直飞出，碰到左右墙壁会弹一下。
- **飞刀**：开局就有。每 **2 秒**连射三发，颜色是红、红、紫。
- **法术书**：升级时可以拿到。每 **5 秒**连射七发：蓝、蓝、蓝、白、白、紫、紫。两件武器会一起转。
- 打中**不同颜色**只造成一点基础伤害，这发子弹会粘在怪物团上。
- **同色连上 3 颗**才会炸掉相连的那一团，并且这一色的每只怪物都吃到连锁伤害，再附加流派效果。不够 3 颗不会爆。
- 第 4 颗起，每多 1 颗，连锁伤害 **×1.15**。连上 **6 颗及以上**是大招。
- 炸掉之后，不再连着天花板的怪物会掉下去。
- 整团压过底部的红线，这局就结束。
- 消除一段之后会升级。战斗暂停，从 3 项强化里选 1 个，效果只留到这局结束。
- 开始、升级和结算也可以用键盘：回车或空格确认，`1` / `2` / `3` 选择。

## 颜色

- **红 · 火焰爆发**：炸开的位置再伤周围一圈。
- **蓝 · 冰冻**：整团气泡暂时几乎不再下压。
- **绿 · 藤蔓**：缠住旁边的怪物并造成伤害。
- **紫 · 闪电**：跳到附近的怪物身上。
- **白**：不是攻击。连上之后缩短武器冷却，大招缩短得更多。

## 一局怎么走

没有地图，也没有旁边的赛道。顶上的怪物会一波波补上来。升级拿到的强化，包括法术书，都只在这一局里有效。气泡碰到你就失败，结算界面可以再来一局。
