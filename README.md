# 消消乐 Rogue

一个用 Godot 4.6 制作的三消肉鸽小游戏。每一层是一场限步战斗：交换宝石、凑成三连，在步数用完之前打掉敌人的气血。

## 如何打开

1. 安装 [Godot 4.6](https://godotengine.org/download) 标准版（不需要 .NET）。
2. 打开 Godot，选择「导入」，选中本目录的 `project.godot`。
3. 导入完成后按 F5，或点击编辑器右上角的运行按钮。

主场景是 `scenes/main.tscn`。画面只用 ColorRect、Polygon2D 和引擎自带控件，没有外部素材包。中文界面会使用系统里已有的中文字体（例如微软雅黑、苹方、Noto Sans CJK、文泉驿微米黑）。

## 操作

- **鼠标**：点击一颗宝石，再点击相邻的一颗，交换它们。也可以按住一颗宝石拖向相邻格。
- **键盘**：
  - 方向键或 WASD 移动光标
  - 空格或回车确认当前光标上的宝石（和鼠标点击相同）
  - 开始界面、通关和失败界面：回车或空格
  - 强化选择：`1` / `2` / `3`
- 只有交换后能形成 **3 连或更长** 时，交换才会生效，并消耗 **1 步**。不能消除的交换会弹回，不扣步。
- 消除后，上方的宝石落下，空位补上新宝石。如果因此再次连成三连，会继续结算（连锁），且不再额外扣步。
- **4 连、5 连** 比 3 连造成更多伤害。同一个形状里的横连和竖连会分别计算伤害。

## 肉鸽流程

1. 从开始界面进入一局。本局使用一个随机种子，棋盘和强化选项都由它决定。种子显示在战斗界面上。再开一局会换新种子，强化也会重新抽取。
2. 一局共 **5 层**。每层有步数上限和一名敌人。
3. 消除对敌人造成伤害。气血降到 0 就过关；步数先归零，这局就失败。
4. 还没到最后一层时，过关后会出现 **3 个强化**，从中选 **1** 个。强化会保留到本局结束，同一项可以多次拿到并叠加。
5. 打完第 5 层即通关。通关或失败后都可以立刻再来一局。

强化包括：

- **步数充盈**：之后每层额外 +3 步
- **锋锐宝石**：消除和爆弹的伤害提高
- **开场爆弹**：每层开始时引爆一块随机 3×3，不消耗步数
- **连锁余波**：连锁消除造成额外伤害
- **四连精通**：4 连及以上额外伤害
- **厚积伤害**：每次消除的基础伤害提高
