# 消消乐 Rogue

一个用 Godot 4.6 制作的实时肉鸽。左边的宝石从顶端落下，靠着左右和底部的墙叠起来。右边是一条竖着的赛道：你站在顶端，敌人从底端往上走。划过彼此挨着的同色宝石来施法，法术会在同一刻打进右边的赛道。

## 如何打开

1. 安装 [Godot 4.6](https://godotengine.org/download) 标准版（不需要 .NET）。
2. 打开 Godot，选择「导入」，选中本目录的 `project.godot`。
3. 导入后按 F5，或点编辑器右上角的运行按钮。

主场景是 `scenes/main.tscn`。画面用 ColorRect、Polygon2D 和引擎自带控件，没有外部素材包。中文会用系统里已有的字体（微软雅黑、苹方、Noto Sans CJK、文泉驿微米黑等）。

## 操作

- **一笔连线**：按住鼠标划过宝石。方向不限，也不用对齐格子，像没有格子的连连看。松开鼠标结算这一笔。
- 宝石从场地顶端慢慢落下。左边、右边和底部是墙，宝石会叠住。堆到顶就暂停生成，直到空出位置。
- 颜色以第一颗碰到的宝石为准。后面的宝石必须是同一种颜色，并且和上一颗已经连上的宝石挨在一起，才会算进这一笔。
- 同色至少连上 **3 颗** 才会消除并施法。不够 3 颗什么都不会发生，宝石留在原地，连击也不会断。
- 第 4 颗起，每多 1 颗，这次伤害 **×1.15**。连上 **6 颗及以上** 会施放该颜色的大招。
- 消掉的位置会空出来，上面的宝石跟着落下。
- 成功的连击会抬高连击槽，并给一个短暂的伤害加成。连得越高，闪屏、震屏和声音越响。停太久不划，连击会掉。
- 划的时候右边的战斗不会停。成功的一笔会立刻打在右边：闪光、冰冻、藤蔓或雷电。
- 连着击倒敌人一段之后会升级。战斗暂停，从 3 项强化里选 1 个，效果只留到这局结束。
- 开始、选路线、奖赏、升级和结算也可以用键盘：回车或空格确认，`1` / `2` / `3` 选择。商店里 `1` / `2` / `3` 购买，回车离开。

## 颜色

颜色是法术流派，不是同一种攻击。

- **红 · 火焰**：火球、燃烧、爆裂。以伤害为主。
- **蓝 · 寒冰**：冰刺、冰冻、冰墙。偏控制，仍然会打伤害。
- **绿 · 藤蔓**：藤鞭、缠绕，以及一个会暂时攻击的藤灵。
- **紫 · 雷电**：雷击顺着赛道打下去，可以跳到后面的敌人，大招会短暂眩晕。
- **白**：不是攻击流派。3 颗是额外连锁，4–5 颗强化下一发法术，6 颗给一份金币和治疗，类似商店里的小奖赏。

敌人比较耐打，一刀消不掉。燃烧、冰冻、缠绕、眩晕和藤灵都会留在右边，你可以接着划下一刀。

## 一局怎么走

开局从 **3 条路线**里选 1 条。每条路是排好的一串节点，按顺序走，没有地图：

- 普通战斗
- 精英
- 商店（花钱买伤药或强化）
- 奖赏（白拿一项，留到本局结束）
- 首领

打完首领就通关。生命归零就失败。结算界面可以再来一局，种子和商品都会重抽。升级时拿到的强化也只在这一局里有效。
