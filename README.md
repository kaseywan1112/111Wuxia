# 消消乐 Rogue

四壁围住的弹球搜刮。你上下左右移动，把球向上打出去。怪物在场里走，打掉会掉金币和装备。

捡起来不算带走。保全背包只能放一件。休整时可以抽出，身上的金币和装备才会留下。倒下，或这一局没抽成，没保全的都会丢掉。

## 怎么玩

场地会往上卷，怪物从顶上下来。WASD 或方向键在框里移动。左右是墙。空格或鼠标左键把球向上打出。一段打完后按回车继续。

每打掉 4 只，可以在伤害、多弹、接球、射速里选一个。这些只在这一局里有效。

抽出的金币和装备留在营地。在那里可以升级第一件、给它镶一颗赤珠、点三个天赋（稳手、眼尖、旧伤），或者拆一件换成金币。局内的金币付不了这些。

- **连弹**：开局就有。球一直弹，直到时间到。
- **回手**：只有一颗球，接住才能再射。接住给一点金币，并短暂提高伤害。
- **重锤**：慢、打得重、弹几下就停。

后两件在休整时拿，怪物也会掉。区域越后面，怪越多、血越厚。打完一段会出现首领，首领之后一定能休整。第一段战斗之后也会先休整一次。

休整时：`1` 把身上第一件放进背包，`2` 回手，`3` 重锤，`4` 连弹，`E` 抽出，回车继续。

抽出的东西写在本机 `user://extract_stash.cfg`。

## 运行

