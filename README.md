# 消消乐 Rogue

左边是窄道，右边是宝石盘。窄道往上卷，不会清场。怪物从顶上一直来，开头很少。漏过你身边会扣血，扣光这一局就结束。

右边按住鼠标，把相邻的同色宝石连成一条。只能上下左右，可以转弯，不能斜着，也不能重复经过。松开时至少要有 3 颗，宝石才会消掉、落下、补上，并把这一下打进左边的窄道。

三颗特殊宝石很小：逆珠让球反过来，分珠在几秒里多出一颗球，凝珠让怪物停一下。

经验球要走过去捡。装备直接进背包。保全背包只能放一件。到点会休整，可以抽出。首领也是到点才来，打完窄道继续。倒下，没保全、没抽出的都会丢掉。

## 怎么玩

左边是窄道。WASD 或方向键移动。左右是墙。空格或在窄道上点击，也能把球向上打出。右边划宝石才会把连击打进去。

走进经验球才会拿到经验和金币。凑够 3 个经验，可以在伤害、多弹、接球、射速里选一个。这些只在这一局里有效。

抽出的金币和装备留在营地。在那里可以升级第一件、给它镶一颗赤珠、点三个天赋（稳手、眼尖、旧伤），或者拆一件换成金币。局内的金币付不了这些。

- **连弹**：开局就有。球一直弹，直到时间到。
- **回手**：只有一颗球，接住才能再射。接住给一点金币，并短暂提高伤害。
- **重锤**：慢、打得重、弹几下就停。

后两件在休整时拿。区域越后面，怪越耐打，同时在场的也会多一点。休整和首领按时间出现，窄道本身不会清完。

休整时：`1` 把身上第一件放进背包，`2` 回手，`3` 重锤，`4` 连弹，`E` 抽出，回车继续。

抽出的东西写在本机 `user://extract_stash.cfg`。
