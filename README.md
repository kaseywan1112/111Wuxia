# 消消乐 Rogue

左边是法师，守着底下的城墙。珠子会自己蓄力，蓄满就往上射。怪物从顶上走下来，碰到城墙就扣血，城墙归零这一局结束。

右边是 8×8 的交换。点两颗相邻宝石。三颗同色才消，落下补上，落出来的新三连也会消。

五种颜色是五把武器。刚消掉的颜色变成自动射击的那一把。

- **赤·直击**：打中第一个。四连连射 2 发。五连是一发重弹。
- **青·贯穿**：穿过去，一路打。四连 2 发。五连全场打一下。
- **翠·溅射**：打中一片。四连连射 3 发。五连是一场爆。
- **紫·迟滞**：让怪变慢。四连 2 发。五连让全场变慢。
- **金·护体**：补城墙。四连连补 3 次。五连是一面大盾。

经验球飘到法师身边才捡。装备直接进背包。保全背包只能放一件。到点会休整，可以抽出。首领也是到点才来。倒下，没保全、没抽出的都会丢掉。

## 怎么玩

左边不用走。右边点一颗，再点相邻的一颗。

经验球飘到法师身边才会拿到经验和金币。凑够 3 个经验，可以在伤害、多打一个、护体、射速里选一个。这些只在这一局里有效。

抽出的金币和装备留在营地。在那里可以升级第一件、给它镶一颗赤珠、点三个天赋（稳手、眼尖、旧伤），或者拆一件换成金币。局内的金币付不了这些。

区域越后面，怪越耐打，同时在场的也会多一点。休整和首领按时间出现，城墙还在就继续。

休整时：`1` 把身上第一件放进背包，`E` 抽出，回车继续。

抽出的东西写在本机 `user://extract_stash.cfg`。

## 运行

用 Godot 4.6 打开这个项目。规则检查：
