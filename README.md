# 消消乐 Rogue

一个用 Godot 4.6 制作的单屏肉鸽。彩色怪物从上方走下来，你站在底部自动攻击。同色是重击，还能连锁到这一色的其他怪物。别的颜色只造成基础伤害。没有泡泡，攻击也不会粘在怪物身上。

## 如何打开

1. 安装 [Godot 4.6](https://godotengine.org/download) 标准版（不需要 .NET）。
2. 打开 Godot，选择「导入」，选中本目录的 `project.godot`。
3. 导入后按 F5，或点编辑器右上角的运行按钮。

主场景是 `scenes/main.tscn`。画面用 ColorRect、Polygon2D 和引擎自带控件，没有外部素材包。中文会用系统里已有的字体（微软雅黑、苹方、Noto Sans CJK、文泉驿微米黑等）。

## 操作

- 武器会自己攻击，近战挥砍，远程往上射。
- **同色**：打中武器颜色的怪物是重击，屏幕上其他同色怪物吃到连锁伤害。
- **异色**：只造成基础伤害。
- 怪物走到你身边，这局就结束。
- 开始、结算：回车或空格再开一局，`E` 打开装备。
- 升级：`1` / `2` / `3` 选遗物。

## 局内遗物

击杀一段之后升级，3 选 1，只留到这局结束，可以重复拿、叠层。

- **猛击**：伤害 +15%。
- **疾射**：攻击间隔缩短 15%。
- **连锁**：同色连锁伤害 +25%。
- **双发**：远程多一发弹，近战挥击更宽。
- **长刃**：近战范围 +40%。

## 局外装备

怪物会掉装备。部位是武器、护甲、饰品。同一套装穿上两件就有套装效果。装备存在本地，下一局还在。整理装备的界面在开局前和失败后。

- **朴刀**：开局就有。近战，红色，没有套装。
- **赤焰**：赤焰弓（远程，红）和赤焰甲（伤害 +10%）。两件：同色伤害 +30%。
- **寒铁**：寒铁剑（近战，蓝，挥得更远）和寒铁坠（攻击间隔 -10%）。两件：攻击间隔再 -20%。
- **青藤**：青藤弓（远程，绿）和青藤甲。两件：远程多一发侧向弹。

## 一局怎么走

没有地图。怪物一波波从顶上走下来。遗物这局结束就没了，装备还在。
