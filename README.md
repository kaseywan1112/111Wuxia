# 消消乐 Rogue

一个用 Godot 4.6 制作的实时三消肉鸽。左边是宝石盘，右边是一条竖着的赛道：你站在顶端，敌人从底端往上走。划一条同色宝石来施法，法术会飞进右边的赛道。

## 如何打开

1. 安装 [Godot 4.6](https://godotengine.org/download) 标准版（不需要 .NET）。
2. 打开 Godot，选择「导入」，选中本目录的 `project.godot`。
3. 导入后按 F5，或点编辑器右上角的运行按钮。

主场景是 `scenes/main.tscn`。画面用 ColorRect、Polygon2D 和引擎自带控件，没有外部素材包。中文会用系统里已有的字体（微软雅黑、苹方、Noto Sans CJK、文泉驿微米黑等）。

## 操作

- **划线**：按住鼠标，从一颗宝石拖到相邻的同色宝石。只能上下左右，可以转弯，不能斜着连，也不能重复经过同一颗。往回拖一格会撤销。
- 松开时至少要有 **3 颗**。不够 3 颗就是一次断连，连击归零。
- 第 4 颗起，每多 1 颗，这次伤害 **×1.15**。连到 **6 颗及以上** 会额外施放该颜色的大招。
- 成功的连击会抬高连击槽，并给一个短暂的伤害加成。连得越高，闪屏、震屏和声音越响。停太久不划，连击也会掉。
- 划线的时候右边的战斗不会停，也不会被菜单挡住。
- 开始、选路线、奖赏和结算也可以用键盘：回车或空格确认，`1` / `2` / `3` 选择。商店里 `1` / `2` / `3` 购买，回车离开。

## 颜色

颜色是法术流派，不是同一种攻击。

- **红 · 火焰**：火球、燃烧、爆裂。以伤害为主。
- **蓝 · 寒冰**：冰刺、冰冻、冰墙。偏控制，仍然会打伤害。
- **绿 · 藤蔓**：藤鞭、缠绕，以及一个会暂时攻击的藤灵。
- **紫 · 雷电**：雷击顺着赛道打下去，可以跳到后面的敌人，大招会短暂眩晕。
- **白**：不是攻击流派。3 连是额外连锁，4–5 连强化下一发法术，6 连给一份金币和治疗，类似商店里的小奖赏。

敌人比较耐打，一条链消不掉。燃烧、冰冻、缠绕、眩晕和藤灵都会留在右边，你可以接着划下一条。

## 一局怎么走

开局从 **3 条路线**里选 1 条。每条路是排好的一串节点，按顺序走，没有地图：

- 普通战斗
- 精英
- 商店（花钱买伤药或强化）
- 奖赏（白拿一项，留到本局结束）
- 首领

打完首领就通关。生命归零就失败。结算界面可以再来一局，种子和商品都会重抽。
